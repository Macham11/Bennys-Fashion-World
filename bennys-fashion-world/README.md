# Benny’s Fashion World: everything in one folder

## 1. static-website
Plain HTML, CSS and JavaScript. No installation needed.
- Open `static-website/index.html` by double-clicking it.
- To put it online, drag the `static-website` folder into Vercel or Netlify.
- Edit products, bank details and reviews at the top of `static-website/assets/app.js`.

## 2. nextjs-website
The same website built with Next.js (needs Node.js 18 or newer).
- In the `nextjs-website` folder run `npm install`, then `npm run dev`, then open http://localhost:3000
- To put it online, push the folder to GitHub and import it on vercel.com.
- Edit products, bank details and reviews in `nextjs-website/lib/data.js`.
- Put your fabric photos in `nextjs-website/public/images/` and point to them with `img:"/images/name.jpg"`.

Pick one version. Both have the same pages: Home, Shop, Product, Checkout, About, Contact, FAQ, Privacy, Terms and Returns.

## Before you go live
1. Add your own products, prices and photos (the shop is empty until you do).
2. Add your bank name, account number and account name for checkout.
3. Add your real customer reviews (the section stays hidden until you do).
4. Add your social media links (search for `href="#"`).
5. Edit the Privacy, Terms and Returns pages to match how you run your business.
